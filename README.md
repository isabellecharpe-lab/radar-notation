# Radar de notation

Outil web qui compare jusqu'à trois produits notés dans des grilles Excel, sur un radar à 7 axes (3 familles, 7 critères, sous-critères).

## Utilisation

1. Ouvrir la page.
2. Charger un fichier Excel par produit (format `NOTE_FINALE` : Famille, Critère, Sous-critère, Coefficient, Note /10) et saisir son nom.
3. Cliquer sur « Afficher le radar ».
4. Cliquer sur le nom d'un produit pour afficher ou masquer son radar.
5. Choisir le mode Simple (moyenne par critère) ou Détaillé (toutes les notes des sous-critères).
6. Exporter le visuel en PNG ou JPEG.

Les fichiers sont lus dans le navigateur : aucune donnée n'est envoyée sur un serveur.
